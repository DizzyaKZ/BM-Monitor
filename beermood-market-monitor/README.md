# MOOD Raw Material Price Monitor (г. Алматы)
**Автономный сервис ежедневного мониторинга цен сырья для холдинга MOOD GROUP**
*Специализация: Молочное (CHEESY), Мясное (MEAT), Хлебное (BAKE) производство и Специи (SPICY MOOD LAB)*  
*Локация: Казахстан, г. Алматы, ул. Жарокова 137/1 (ЖК «Арай», блок Г3)*

---

## 1. Назначение системы
1. **Ежедневный сбор и мониторинг котировок в Алматы:**
   - **Физические рынки:** «Алтын Орда» (крупный опт), «Зеленый Базар» (павильоны мяса и фермерского молока), «Оптовка» (ул. Розыбакиева / Райымбека).
   - **Сетевые гипермаркеты и B2B базы:** METRO Cash & Carry (HoReCa/B2B опт), Magnum Cash & Carry.
   - **Онлайн-площадки:** Kaspi Магазин / Kaspi Доставка, Arbuz.kz, Satu.kz B2B.
   - **Прямые поставщики и дистрибьюторы:** закваски Sacco/Danisco (Биоком, Milk-Trade), мясокомбинаты Алматинской обл. (Бижан, KazBeef), мукомольные предприятия (Puratos, Цесна, Азия Агро Фуд), оптовые импортеры специй.
2. **Динамика и аналитические графики:**
   - Временные ряды средневзвешенных цен за 7, 14 и 30 дней.
   - Коридор волатильности (минимальная и максимальная цена на рынке Алматы).
   - Индикаторы суточного (24ч) и недельного (7д) трендов, выявление лучших поставщиков по каждой позиции.
3. **Бесшовный перенос в BEERMOOD Master ERP:**
   - Прямая отправка в один клик по REST API на endpoint `/api/market-prices` (соответствует схеме `raw_material_prices`).
   - Экспорт готового SQL-дампа `INSERT INTO raw_material_prices ... ON DUPLICATE KEY UPDATE` для MySQL/MariaDB на сервере PS.kz.
   - Выгрузка в CSV для Excel и бухгалтерского контура 1C.

---

## 2. Быстрый запуск (Node.js без внешних npm-зависимостей)
Приложение построено на базе стандартных библиотек Node.js (`http`, `fs`, `path`, `url`) и не требует установки сторонних npm-пакетов.

```bash
# 1. Запуск сервера:
node server.js

# 2. Откройте в браузере:
http://localhost:4300
```
